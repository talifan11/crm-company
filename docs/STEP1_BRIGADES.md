# Шаг 1: Бригады и персонал

## Реализовано

### Backend (Python/FastAPI)

#### Модели данных
- **Brigade** — бригада (название, руководитель, состав, зона, телефон, транспорт, статус)
- **BrigadeShift** — смена бригады (начало/конец, статус, геопозиция начала/конца)
- **BrigadeLocation** — геолокация бригады (трекинг с мобильного, точность, скорость)
- **CoverageZone** — зона покрытия (заглушка для Шага 5)

#### API эндпоинты
- `GET /api/v1/brigades` — список бригад с фильтрацией по статусу
- `GET /api/v1/brigades/online` — бригады онлайн с последней геолокацией
- `POST /api/v1/brigades` — создать бригаду (только admin)
- `GET /api/v1/brigades/{id}` — получить бригаду
- `PUT /api/v1/brigades/{id}` — обновить бригаду (только admin)
- `DELETE /api/v1/brigades/{id}` — удалить бригаду (soft delete, только admin)

#### Миграция Alembic
- `003_brigades.py` — создание таблиц brigades, brigade_shifts, brigade_locations, coverage_zones
- GiST-индексы на геометрии
- BTree-индексы на status, brigade_id, recorded_at

#### Тесты
- `test_brigades.py` — 8 тестов (CRUD, фильтрация, онлайн-статус, soft delete, авторизация)

### Frontend (React/TypeScript)

#### Типы
- `Brigade`, `OnlineBrigade`, `BrigadeStatus`
- `BRIGADE_STATUS_LABELS` — русские названия статусов
- `BRIGADE_STATUS_COLORS` — цвета для статусов

#### Моковые данные
- `mockBrigades` — 4 бригады с разными статусами
- `mockOnlineBrigades` — 3 бригады онлайн с геолокацией

#### Страница /brigades
- Список бригад с карточками
- Фильтрация по статусу
- Карточка выбранной бригады справа
- Отображение: название, статус, состав, телефон, транспорт, примечания

#### Слой бригад на карте
- Круги с цветом по статусу (зелёный/жёлтый/синий/серый/красный)
- Метки с названием бригады
- Клик по бригаде — alert с информацией
- Hover — курсор pointer

#### Навигация
- Добавлен пункт "Бригады" в Sidebar
- Роут `/brigades` в App.tsx

### Статусы бригад
- **active** (зелёный) — свободна
- **on_ticket** (жёлтый) — на заявке
- **en_route** (синий) — на выезде
- **day_off** (серый) — выходной
- **inactive** (красный) — неактивна

## Использование

### API
```bash
# Получить список бригад
GET /api/v1/brigades

# Получить бригады онлайн
GET /api/v1/brigades/online

# Создать бригаду (требует admin)
POST /api/v1/brigades
{
  "name": "Бригада №5",
  "lead_user_id": 10,
  "member_ids": [10, 11, 12],
  "phone": "+79991234567",
  "vehicle": "ГАЗель",
  "status": "active"
}
```

### UI
1. Перейти на страницу `/brigades`
2. Выбрать бригаду из списка
3. Просмотреть детали в карточке справа
4. На карте `/map` видны бригады онлайн с цветовой индикацией
